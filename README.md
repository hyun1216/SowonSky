# 🎈 소원하늘 (SowonSky)

> 깊은 밤하늘과 새벽빛 감성의 웹 애플리케이션으로, 세계 지도에서 국가를 선택하고 밤하늘에 소원 풍선을 띄우며 서로의 꿈을 응원하는 몽환적인 서비스입니다.

---

## ✨ 핵심 기능

1. **세계 지도 뷰 (World Map View)**
   - `react-simple-maps` 기반의 평면 세계 지도 (다크 slate 스타일)
   - 국가 Hover 시 네온 파스텔 톤 하이라이트 및 실시간 툴팁 (국가명 + 등록된 소원 개수)
   - 국가 클릭 시 부드러운 전환 효과와 함께 해당 국가의 '소원하늘'로 이동
   - 인기 국가(대한민국, 일본, 미국 등) 빠른 이동 칩 지원

2. **하늘 뷰 (Sky View)**
   - 선택된 국가의 국기 이모지, 국가명 및 상공에 떠있는 소원 개수 카운트
   - `Framer Motion` 기반으로 화면 아래에서 위로 천천히 떠오르는 3D 감성의 파스텔 톤 풍선 애니메이션
   - 풍선 클릭 시 상세 모달 오픈 및 '❤️ 소원 응원하기' 기능 (하트 팝업 인터랙션 & 실시간 카운트 업)
   - 우하단 플로팅 액션 버튼 (FAB): "🎈 소원 띄우기"

3. **소원 작성 모달 (Wish Write Modal)**
   - 100자 이내의 감성적인 한 줄 소원 입력
   - 5가지 파스텔 컬러 팔레트 선택 (소프트 핑크, 라벤더, 스카이블루, 민트, 파스텔 옐로우)
   - '하늘로 날리기' 시 즉시 화면 아래에서 둥실 떠오르며 밤하늘에 등록

4. **비주얼 & 인터랙션 디자인**
   - 다크 테마 (`bg-slate-950`) 바탕의 오로라/새벽빛 그라데이션 및 반짝이는 별빛(`BackgroundStars`)
   - 유성/별똥별 애니메이션 효과

---

## 🚀 시작하기

```bash
# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 프로덕션 서버 실행
npm start
```
